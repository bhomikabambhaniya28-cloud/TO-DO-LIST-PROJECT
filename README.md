# Todo List App

A beautiful, feature-rich todo list application built with vanilla JavaScript.

## Features

- ✅ Add new tasks
- ✅ Mark tasks as complete/incomplete
- ✅ Delete individual tasks
- ✅ Filter tasks (All/Active/Completed)
- ✅ Clear all completed tasks
- ✅ Persistent storage (localStorage)
- ✅ Responsive design
- ✅ Smooth animations
- ✅ Task counter
- ✅ Keyboard support (Enter to add)

## Technologies Used

- HTML5
- CSS3 (with animations and responsive design)
- JavaScript (ES6+)

## How to Use

1. Clone or download this repository
2. Open `index.html` in your web browser
3. Start managing your tasks!

## Usage Instructions

- **Add a task**: Type in the input field and click "Add Task" or press Enter
- **Complete a task**: Click the checkbox next to the task
- **Delete a task**: Click the "Delete" button on any task
- **Filter tasks**: Use the filter buttons to view all, active, or completed tasks
- **Clear completed**: Click "Clear Completed" to remove all completed tasks at once

## Data Persistence

All your tasks are automatically saved to your browser's localStorage. Your tasks will remain even after closing or refreshing the browser.

## Browser Support

Works on all modern browsers including:
- Chrome
- Firefox
- Safari
- Edge

## Customization

You can easily customize the colors and styling by modifying the CSS variables in the `style.css` file.
